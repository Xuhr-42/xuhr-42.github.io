# Xuhr-42.github.io

Bilingual academic homepage, blog, and file archive for Haoran Xu.

## Updating the site

- Profile content lives in `index.html`.
- Blog posts live in `_posts/` and use the filename format `YYYY-MM-DD-title.md`.
- Download metadata lives in `_data/files.yml`; downloadable assets can be placed in `files/`.
- The English/Chinese switch is handled by `assets/js/site.js`.

The site is designed for GitHub Pages and uses only built-in Jekyll features.
